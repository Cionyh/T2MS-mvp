





# Text2MySite™ (T2MS)

**SMS-to-Website Alert Tool** - Update your website content instantly by sending a text message.

## Overview

Text2MySite™ is a SaaS platform that enables business owners to update their website content in real-time by simply sending SMS messages. No technical skills required - just text and your message appears on your website instantly.

## Key Features

- 📱 **SMS-to-Website Updates**: Send text messages that appear on your website instantly
- 🎨 **Customizable Widgets**: Banners, popups, modals, tickers, and fullscreen displays
- 🌐 **Multi-Platform Support**: Works with WordPress, Wix, Shopify, Squarespace, and more
- 👥 **Team Management**: Invite team members and manage permissions
- 📊 **Analytics Dashboard**: Track messages and website performance
- 💳 **Subscription Plans**: Flexible pricing with Stripe integration
- 🔒 **Secure & Compliant**: Phone verification, secure authentication, and SMS compliance

## How It Works

1. **Register** your website and verify your phone number
2. **Customize** your widget appearance and embed it on your site
3. **Send** a text message from your verified phone
4. **Display** your message instantly on your website

## Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma, PostgreSQL
- **Services**: Twilio (SMS), Stripe (Payments), Better Auth (Authentication)
- **Analytics**: PostHog
